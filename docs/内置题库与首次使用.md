# 内置题库与首次使用

默认是内置元数据索引+按需缓存图片，不是要求老师自备题库的工具壳。索引由作者现有公开题库版本web-full-0.3.8生成，包含6586条题答引用；不嵌入原题正文、答案文本、原卷PDF或图片。

来源为作者现有公开站点lauraphysics.com及其Cloudflare Pages域名。图片路径和内容哈希随索引固定，下载后校验哈希并解码；不匹配不进入出卷。只获取所需候选及已选题的题目和答案，不每次全量下载。

首次运行会准备专用Python环境及PDF依赖。Mac入口使用Astral官方uv安装器，设置UV_NO_MODIFY_PATH并将工具、Python和缓存约束到本工具目录；不改系统Python或shell配置。Windows入口不修改执行策略。

题库下载代码不上传板书、学生资料或提示词；宿主模型如何处理图像由平台设置决定。无网络且所需图片尚未缓存时明确失败，不能编造试卷或要求老师在不知情下购买别的服务。

高级用户仍可主动绑定本机授权题库；已有主动绑定的题库不会被内置索引覆盖。代码MIT许可与第三方考试材料权利分开。
